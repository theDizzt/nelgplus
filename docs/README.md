# Never Ending Level Game ++ 설계 문서

이 디렉터리는 게임의 장기 개발 방향과 구현 규칙을 기록한다. 새로운 레벨을 만들거나 공통 시스템을 변경하기 전에 관련 문서를 확인한다.

- [PRODUCT_DIRECTION.md](./PRODUCT_DIRECTION.md): 게임의 정체성, 목표와 개발 우선순위
- [LEVEL_DESIGN.md](./LEVEL_DESIGN.md): 퍼즐과 Reunion·Warp Zone 설계 규칙
- [TECHNICAL_ARCHITECTURE.md](./TECHNICAL_ARCHITECTURE.md): 코드 구조와 공통 기능의 책임
- [CONTENT_PIPELINE.md](./CONTENT_PIPELINE.md): 이미지·폰트·음악·효과음 관리 규칙
- [QUALITY_ASSURANCE.md](./QUALITY_ASSURANCE.md): 레벨 테스트와 배포 전 검증 기준

게임 내 정답을 직접 기록하는 공략은 저장소에서 추적하지 않는 `walkthrough.md`에 둔다. 이 디렉터리에는 정답보다 설계 의도와 유지보수 규칙을 기록한다.
