# Never Ending Level Game ++ Design Documents

This directory records the game's long-term development direction and implementation rules. Review the relevant documents before creating a new level or changing a shared system.

- [PRODUCT_DIRECTION.md](./PRODUCT_DIRECTION.md): Game identity, goals, and development priorities
- [LEVEL_DESIGN.md](./LEVEL_DESIGN.md): Puzzle, Reunion, and Warp Zone design rules
- [TECHNICAL_ARCHITECTURE.md](./TECHNICAL_ARCHITECTURE.md): Code structure and shared-system responsibilities
- [CONTENT_PIPELINE.md](./CONTENT_PIPELINE.md): Image, font, music, and sound-effect management
- [QUALITY_ASSURANCE.md](./QUALITY_ASSURANCE.md): Level tests and pre-deployment verification
- [HALL_OF_FAME.md](./HALL_OF_FAME.md): Static JSON record format, ranking, and editing procedure
- [WINNER_REPORTING.md](./WINNER_REPORTING.md): Discord relay, hidden-password field, and Vercel configuration

Store direct game solutions in the untracked `walkthrough.md` file. These design documents should record intent and maintenance rules rather than puzzle answers.
